# 引用チェックの練習 (わざと誤りを入れた参考文献リスト)

## ねらい

参考文献リスト (`refs.bib`) には、次のような誤りが紛れ込むことがある。

- 実在しない論文
- 実在するが、発行年や雑誌名が違う論文
- 実在するが、撤回された論文

この練習用の `refs.bib` には5件の文献があり、うち3件にこうした誤りをわざと入れてある。ツール (citeguard) で見つかることを体験する。

**このフォルダの文献は、実際の原稿に絶対にコピーしないこと。**

## 使うファイル

- `refs.bib`: 練習用の参考文献リスト (5件)
- `draft.md`: 5件すべてを引用した練習用の短い英文。意味のある主張は書いていない

## やり方

AIチャットに次のように頼む。

```text
@demo/citation_check/refs.bib の citation をチェックして
```

コマンドで直接実行する場合は、ルートから次のように実行する (`<メールアドレス>` は自分のものに置き換える)。

```text
citeguard --input-file demo/citation_check/refs.bib --out <レポートの出力先> --all --email <メールアドレス>
```

## このツールが見ないこと

citeguard が見るのは、**書誌が実在するか・撤回されていないか**までである。**引用した論文が、それを付けた文の主張を本当に支えているかは見ない。** そこは著者の仕事になる。

リポジトリの `CLAUDE.md` の「引用チェックの二層」には、こう書いてある。

> - `citation_verify` (citeguard) が見るのは**書誌の実在・撤回**だけ。引用が本文の主張を支えているかは見ない。
> - 脱稿前に 1 回、本文の引用ごとに「引用文＋支えるべき主張」を並べて原文で対応を確認する工程を入れる (`citation_verify` SKILL.md の "Scope limit" 節)。書誌チェックの通過を「引用は大丈夫」と読み替えない。

## 注意

- 結果は、実行した時点の Crossref / PubMed の内容に左右される。上の答えは、2026-10-11 に citeguard 0.3.1 で実行した結果の記録である。違う日・違うバージョンでは、分類の文言や候補が変わることがある。
- このフォルダの文献を、実際の原稿の `refs.bib` に入れない。
